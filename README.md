# C++ Junior

Личный интерактивный тренажёр основ C++ на русском языке: переменные, условия и циклы.

## Возможности

- 9 занятий по схеме: 10 минут теории, 40 минут практики, 10 минут повторения.
- 27 задач: пользователь вводит вывод программы, тренажёр проверяет ответ.
- Подсказки и разбор, доступный только после непустой попытки.
- 50 XP за каждую впервые решённую задачу, 6 уровней и карта прогресса.
- Таймер, серия дней с практикой и сохранение в `localStorage`.
- Выгрузка прогресса в JSON и адаптивный интерфейс.

Маршрут «Junior · основы» — первый учебный рубеж. Для работы Junior нужны дальнейшие темы и практика разработки. Тренажёр проверяет вывод готовых фрагментов; он не компилирует произвольный пользовательский C++.

## Локальный запуск

Установка npm-пакетов и сборка не нужны. Из корня проекта запустите:

```sh
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. На некоторых системах команда Python называется `python3` или `py`.

Открывайте сайт через HTTP-сервер: ES-модули не рассчитаны на запуск через `file://`.

## Проверки

Нужны Node.js 20+ и компилятор `g++` в `PATH` с поддержкой C++17.

```sh
npm test
```

Тесты проверяют блокировку разбора до попытки, начисление XP без повторных наград, сохранение и восстановление данных, нормализацию ответов и завершение маршрута. Все 27 эталонных ответов также сверяются с реальным выполнением C++-кода.

## Структура

```text
dist/
  index.html      — страница приложения
  style.css       — оформление и адаптивность
  app.js          — интерфейс, таймер и сохранение
  course.js       — учебные материалы, задачи и правила прогресса
tests/
  course.test.mjs — проверки логики и эталонных ответов
```

Для статического хостинга используйте содержимое `dist/`. Приватность размещённого сайта настраивается на стороне выбранного хостинга. Само приложение не содержит серверной авторизации.

## Данные и ограничения

Прогресс хранится только в текущем браузере и не синхронизируется между устройствами. Очистка данных браузера удалит прогресс. Эталонные ответы находятся в клиентском коде; скрытие разбора — учебная механика, а не защита от просмотра исходников. Шрифты загружаются из Google Fonts; при недоступности используются системные.

Экспорт исходников не содержит привязки к аккаунту и конфигурации приватного размещения ChatGPT Sites.
